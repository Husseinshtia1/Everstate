# EVR-AGRI-RELIABILITY-002

This benchmark is the formal continuation track after `EVR-AGRI-ENTERPRISE-001`.

It evolves the generated Agricultural Agentic OS into an **Agricultural Operations Reliability & Intelligence Platform** whose center is operational exception detection, cross-system impact analysis, governed replanning, execution verification and measurable outcomes.

## North Star

> Make complex agricultural operations continue correctly when reality deviates from the plan.

## Core loop

`Connect → Understand → Detect Exception → Determine Impact → Collaborate → Optimize → Check Policy → Approve → Execute → Verify → Learn → Quantify Value`

## Sequencing rule

Do not start this track until the previous enterprise benchmark has a passing real-run summary. The transition script checks that prerequisite before launching this plan.

## Development order

1. Canonical model + identity graph
2. Connector SDK/control plane
3. Provenance/freshness + World State
4. Event + Exception objects
5. Dependency graph + impact engine
6. Evidence/uncertainty + read-only AI
7. Supervisor + four initial agents
8. OR optimization
9. Deterministic policy + approvals
10. Durable action execution + verification
11. Outcome engine + ROI ledger
12. External integrations/pilots
13. Enterprise/autonomy gates

## Product boundary

This is not a replacement FMIS and not a chatbot-first product. Existing Deere/CropX/ERP/IoT systems remain in place. Everstate is the canonical reliability/control plane that coordinates them when reality deviates from the operating plan.

See `docs/AGRI_OPERATIONS_RELIABILITY_V2.md` for the authoritative product/engineering plan.
